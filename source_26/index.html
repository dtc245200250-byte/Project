Web Technology

HTML stands for HyperText Markup Language. It is used to design web pages using a markup language. HTML is the combination of Hypertext and Markup language. Hypertext defines the link between web pages, while a markup language defines the structure of web pages using tags. HTML is used by browsers to manipulate text, images, and other content into the required format.
