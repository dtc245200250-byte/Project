Các lệnh quan trọng

Kiểm tra Node.js node -v
Kiểm tra npm npm -v
Cài Sass toàn cục npm install -g sass
Kiểm tra Sass sass -v
SCSS → CSS sass scss/styles.scss css/styles.css
Watch mode sass --watch scss/:css/
