# AI Prompt Log

## Prompt 1 — Phân biệt Flexbox và Grid
> Khi một phần tử con phải chiếm chính xác 2 hàng và 2 cột, nên chọn CSS Grid hay Flexbox? Vì sao?

**Kết quả áp dụng:** Chọn CSS Grid cho Dashboard Bento vì yêu cầu kiểm soát đồng thời hàng và cột.

## Prompt 2 — Bootstrap Grid
> Trong Bootstrap 5, `col-sm-4` và `col-md-4` khác nhau thế nào? Khi nào dùng Bootstrap thay vì CSS Grid tự viết?

**Kết quả áp dụng:** Pricing dùng `col-12 col-md-4` để 1 cột trên mobile và 3 cột từ breakpoint md.

## Prompt 3 — Navbar responsive
> Làm thế nào dùng `flex-wrap: wrap` để Navbar tự đẩy menu xuống dòng mà không che Logo?

**Kết quả áp dụng:** Navbar dùng Flexbox, `flex-wrap: wrap`, `gap` và breakpoint nhỏ để tránh tràn nội dung.

## Prompt 4 — Gap
> `gap` hoạt động thế nào trong Flexbox và CSS Grid, và tại sao phù hợp hơn margin rời rạc trong layout này?

**Kết quả áp dụng:** Dùng `gap` cho Navbar và Dashboard để khoảng cách nhất quán, DOM và CSS dễ bảo trì hơn.
