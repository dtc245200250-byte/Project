# Bài tập SASS - Landing Page

Mục tiêu: tái cấu trúc CSS của landing page bằng SASS.

Nội dung gồm navigation/header, sản phẩm nổi bật, số liệu thống kê và footer.

Kiến thức áp dụng: variables, mixins, nesting, responsive và tách mã nguồn SASS với CSS đã biên dịch.

Biên dịch SASS: sass sass/main.scss css/main.css

Theo dõi tự động: sass --watch sass/main.scss:css/main.css
