# Phân tích cấu trúc Website Template

## Website được tham khảo

Bố cục được xây dựng theo kiểu một website giới thiệu doanh nghiệp / studio hiện đại.

## 1. Header

Header nằm ở đầu trang và có nhiệm vụ giới thiệu website bằng tiêu đề lớn và phần mô tả ngắn. Khu vực này sử dụng nền màu nổi bật để tạo điểm nhấn trực quan.

## 2. Navigation Menu

Navigation nằm ngay dưới Header và chứa 4 mục chính: Trang chủ, Giới thiệu, Dịch vụ và Liên hệ. Menu được thiết kế theo chiều ngang trên màn hình lớn và chuyển sang bố cục phù hợp trên thiết bị nhỏ.

## 3. Content Section

Content là phần trung tâm của trang. Khu vực đầu tiên gồm hai phần: đoạn mô tả ở bên trái và vùng hình ảnh ở bên phải. Bên dưới là các card dịch vụ được chia thành 3 cột bằng CSS Grid.

## 4. Footer

Footer nằm cuối trang, hiển thị thông tin bản quyền và phân cấp nội dung bằng dấu chấm (•). Hai nhóm thông tin được bố trí thành hai phía để tạo sự cân bằng.

## Tổng kết

Cấu trúc gồm Header → Navigation → Content → Footer giúp trang web rõ ràng, dễ đọc và dễ mở rộng. HTML chịu trách nhiệm tạo cấu trúc, còn CSS điều khiển bố cục, màu sắc, khoảng cách và khả năng responsive.
