# Source 33 - Responsive Grid với SASS

## Mục tiêu
Luyện tập kỹ năng sử dụng SASS bằng cách tái cấu trúc CSS của bài Responsive Grid.

## Nội dung
- Sử dụng biến SASS để quản lý màu sắc và kích thước.
- Sử dụng mixin để giảm lặp code.
- Sử dụng nesting của SASS cho các thành phần liên quan.
- Tách mã nguồn SASS và CSS đã biên dịch.
- Giữ giao diện responsive theo bài mẫu responsive-grid của CodeGym.

## Cấu trúc
- `index.html`: giao diện HTML.
- `sass/main.scss`: mã nguồn SASS.
- `styles.css`: CSS được biên dịch từ SASS.

## Biên dịch SASS
Nếu máy đã cài Dart Sass:

```bash
sass sass/main.scss styles.css
```

Theo dõi thay đổi:

```bash
sass --watch sass/main.scss:styles.css
```
