# Newsletter Color Lab - Source 37

Bài thực hành xây dựng newsletter bằng Bootstrap và thay đổi palette màu.

## Thành phần

- `index.html`: trang chọn giữa hai phiên bản.
- `newsletter_version1.html` + `style1.css`: palette Ocean Blue.
- `newsletter_version2.html` + `style2.css`: palette Warm Sunset.

## Điểm chính

- Bootstrap 5.3.3 responsive.
- Mỗi phiên bản giữ cùng tinh thần bố cục newsletter nhưng có hệ màu riêng.
- Màu được gom vào CSS variables để dễ chỉnh sửa và thử nghiệm.
- Có điều hướng, nội dung chính, CTA và footer.
